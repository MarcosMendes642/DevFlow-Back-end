Documentação do Backend

Organização de Rotas, Dados e Lógica do DevFlow.

Abaixo estão todas as rotas já configuradas no backend. 🔒 indica rota que exige autenticação via token JWT no header Authorization. O conteúdo desta página não inclui APIs fictícias, apenas a documentação das rotas reais.

Rotas Disponíveis

Rotas de Usuário / Auth
POST /cadastro

Cadastro de usuários. Body: { name, email, senha }. Valida campos obrigatórios, verifica e-mail duplicado (retorna 409 se já existir), faz hash da senha com bcrypt e retorna o token JWT (válido por 7 dias).

201 — token 400 — campos ausentes 409 — e-mail em uso
POST /login

Login de usuários. Body: { email, senha }. Busca o usuário pelo e-mail, compara a senha com bcrypt e retorna o token JWT.

200 — token 400 — campos ausentes 401 — credenciais inválidas
GET /perfil 🔒

Retorna os dados do usuário logado a partir do payload do token JWT. Resposta: { id, email }.

200 — dados do perfil 401 — token ausente / inválido
Rotas de Times
POST /time/criarTime 🔒

Criação de time. Body: { nome }. Cria o time e adiciona o usuário logado como membro com role owner dentro de uma transação no banco.

201 — { message, team } 400 — nome obrigatório 500 — erro ao criar
GET /time/user/:id

Lista os usuários membros de um time pelo ID do time. Retorna id, nome, email, avatar e o papel de cada membro (tmm_role).

200 — lista de membros ⚠️ rota sem autenticação 400 — ID inválido
POST /time/adduser/:id 🔒

Adiciona um membro ao time. Body: { email, role } (role opcional, aceita admin ou member, padrão member). Apenas owner ou admin do time podem adicionar membros. Retorna os dados do membro adicionado (id, nome, email, avatar e tmm_role).

201 — { message, membro } 400 — ID / e-mail / role inválidos 403 — sem permissão 404 — usuário não encontrado 409 — já é membro do time 500 — erro ao adicionar
Rotas de Projetos
GET /projetos/resumo 🔒

Resumo dos projetos do usuário logado. Conta o total de projetos em que ele é membro e quantos foram criados no mês corrente. Resposta: { total, novosNoMes }.

200 — resumo 500 — falha ao buscar
